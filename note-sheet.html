Your note sheet, already built.

One open box per competency, and the box gets drawn, not written. Your prompt says what goes in it, so you divide it however that prompt needs. Print it, rule the same box onto your own paper, or work it on a tablet. All three are graded the same.

The competencies behind it

Per sheet of paper

Before you start

  1. Pick two pens you can tell apart. Pass one is the book, before any video. Pass two is a second color, after the videos, into the same boxes.
  2. Stop pass one while half of every box is still empty. That empty half is the point.
  3. The box is a drawing. Read your prompt first, then divide the box to fit it. Some prompts want a picture with labels running out of it. Some want two panels side by side. Some want a row of small graphs. The division is yours to make.
  4. Words are allowed inside the drawing. A sentence running the width of the box is not. If a box reads like a paragraph, redo it as a word picture.

About the paper

You do not have to print this. Two competencies to a page is what it opens on, and three fits a whole week onto a few sheets. Printing at home, at work or in the library all count.

You do not have to use this sheet at all. Rule one box per competency onto your own paper, or set the same thing up in whatever you already use. A hand ruled sheet is graded exactly the same as a printed one.

Working on a device is fine too. Save the PDF into a drawing app, or draw straight into a notes app, as long as you can still do two passes in two colors. None of this carries points, so use whatever you will actually still be doing in November.

Turning it in

Photograph every sheet in order, in good light, flat on the table. Both colors have to be readable. Combine them into one PDF and upload that to the week’s Canvas assignment. Printed and hand ruled sheets are graded the same way.

Full submission and grading detail is on the note sheet assignment page.
